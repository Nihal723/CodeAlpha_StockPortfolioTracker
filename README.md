# CodeAlpha_StockPortfolioTracker
Stock portfolio tracker built for the **CodeAlpha Python Programming Internship (Task 2)**.

## Features
- Hardcoded dictionary of stock prices
- User enters stock names and quantities
- Calculates per-stock value and total investment
- Optionally saves the result to `.txt` or `.csv`

## Concepts used
dictionary, input/output, basic arithmetic, file handling

## Run
```bash
python stock_tracker.py
```
